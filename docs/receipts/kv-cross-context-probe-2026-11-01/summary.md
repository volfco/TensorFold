# Cross-context hidden-state probe, GLM-5.3-Flash EXL3 on the Spark ring (2026-11-01)

Setup: shared 2048-token chunk S (docs/RESULTS.md prose) prefilled cold under four contexts: alone (S), after a 1024-token README prefix (A+S), after a 1024-token shell-script prefix (B+S), after an 8192-token PATCHES.md prefix (L+S). Tap = mean of the 4 hyper-connection streams after each layer (patch 0430 draft dump, all 45 layers, bf16). Production stack: glm53-tensorfold:dev, latent fp8 KV, TP=2, NoPE model. Dump: /glm53-tf/sessions/kvprobe-20261101/gx10-eb0e-1-1793554398 on spark0 (6.8 GB). Scripts and raw results: ~/kvprobe on spark0.

Metrics per layer on S's rows: relative L2 of the same token's state across two contexts (p50 over 2048 rows), the same for the layer's residual update (tap_l - tap_{l-1}), split into the first 64 tokens of S (head) and the rest (body); baselines: a different token of S in the same context, the neighbouring token. Entropy: order-0 byte-plane model of the bf16 rows (the kv_codec plain model) coded alone (raw), XOR'd against the same token's row in the other context (xor), or int16-subtracted (delta).
